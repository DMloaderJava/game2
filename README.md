# GRAVITY: VOID — архитектура и техстек

2D side-scroller, Survival / Sandbox / RPG / Physics для веб-браузера.
Ключевые требования: высокая производительность при большом количестве физических объектов и модульность (биомы, способности, предметы, ИИ без переписывания ядра).

## Что в репозитории

- `docs/` — полная спецификация архитектуры
- `src/` — эталонная реализация ядра ECS на TypeScript

## Стек (кратко)

- **Язык:** TypeScript 5 (strict)
- **Сборка:** Vite + pnpm
- **Рендеринг:** PixiJS v8 (WebGL, спрайт-батчинг)
- **Физика:** Matter.js (индивидуальная гравитация на тело, sleeping)
- **Звук:** Howler.js (Web Audio API)
- **Хранение:** IndexedDB (`idb` / Dexie.js) + LZ-string сжатие
- **ECS:** собственный легковесный ECS (см. `src/ecs/`)
