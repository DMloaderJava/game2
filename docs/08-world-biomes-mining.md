# GRAVITY: VOID — построение мира, биомы и добыча ресурсов

## 1. Обзор

Система мира отвечает за хранение карты, распределение биомов и ресурсов, разрушение тайлов и физику осыпания оторванных кусков. Мир dividido на 5 типов территорий:

| Территория | Описание | Гравитация |
|------------|----------|------------|
| Поверхность | Открытый мир, поверхностные постройки, дневной цикл | Нормальная (вниз) |
| Подземные пещеры | Сетки туннелей, подземные озера, поддерживающие колонны | Нормальная (вниз) |
| Заброшенные комплексы | Искусственные постройки, лабинуты, техногенные зоны | Нормальная / локальные аномалии |
| Парящие острова | Острова в пустоте, без опоры снизу | Пониженная / нулевая |
| Аномальные зоны | Зоны с нестандартной гравитацией (черные дыры, антигравитация) | Изменяемый вектор и сила |

## 2. Структура данных карты

### 2.1 Чанковая_tile-сетка

Мир делится на **чанки** фиксированного размера (например, 32×32 тайла). Каждый чанк — независимая единица загрузки/выгрузки, что поддерживает беск worlds и высокую производительность при разрушении.

```
World (ECS World)
├── Chunk-сущности (по одной на загруженный чанк)
│   ├── ChunkData { chunkX, chunkY, tileSize, tiles: Tile[], loaded: boolean }
│   └── Transform { x, y }  // позиция чанка в мировых координатах
└── Tile-сущности (внутри чанка, легкие сущности или plain-данные)
    ├── Tile { x, y, type, hardness, health, maxHealth, resourceDrop, ... }
    └── PhysicsBody (если тайл упал и стал физическим обломком)
```

**Почему чанки + тайлы, а не воксели:**
- 2D side-scroller —_tile-сетка достаточно; воксели избыточны для этого жанра.
- Чанки позволяют выгружать遠くшие области из памяти и физики (Matter.js sleeping).
- Разрушение одного тайла не требует пересчёта всего мира — только соседние тайлы в чанке.

### 2.2 Типы тайлов

```typescript
type TileType =
  | 'air'          // пустота
  | 'dirt'         // земля (поверхность, пещеры)
  | 'stone'        // камень (строительство)
  | 'ferrite_ore'  // ферритовая руда
  | 'resonit_ore'  // резонит (грави-технологии)
  | 'biovolume'    // биоволокно (изоляция)
  | 'biogel'       // биогель (лечение)
  | 'ancient_fragment'  // древние фрагменты
  | 'construction' // игрок-постройка (кирпич, сталь, стекло)
  | 'debris'       // обломок (упавший тайл, физический объект)
```

Каждый тайл хранит:
- `type` — тип материала
- `hardness` — сопротивление добыче (1.0 = мягкая земля, 10.0 = базальт)
- `health` / `maxHealth` — текущая прочность тайла
- `resourceDrop` — какой предмет-ресурс спавнится при разрушении
- `dropAmount` — количество dropped items
- `supportRequired` — требует ли тайл опоры снизу (для физики осыпания)
- `fallWhenUnsupported` — при потере опоры тайл падает как физический объект

### 2.3 Физика осыпания и падения

Когда тайл разрушается:
1. Проверяются соседние тайлы (вниз, по диагонали) с `supportRequired = true`.
2. Если у соседа больше нет опоры (вниз — пустота или разрушенный тайл), он помечается как `unsupported`.
3. Неподдерживаемые тайлы конвертируются в **физические обломки** (`debris`):
   - Создаётся новая ECS-сущность с `PhysicsBody` (Matter.js) и `Transform`.
   - Тилл удаляется из чанка (становится `air`).
   - Обломок падает под действием гравитации через общую `GravitySystem` / `PhysicsSystem`.
4. Если обломок попадает на игрока или сущность — наносится урон (интеграция с `DamageSystem`).

Это интегрируется с существующей `GravitySystem`: обломки получают индивидуальную гравитацию или глобальную в зависимости от зоны.

## 3. Распределение ресурсов по биомам

| Ресурс | Поверхность | Подземные пещеры | Заброшенные комплексы | Парящие острова | Аномальные зоны |
|--------|-------------|------------------|----------------------|-----------------|-----------------|
| **Каменные плиты** | Высоко (поверхностный камень) | Высоко | Средко (стены комплексов) | Средко | Низко |
| **Ферритовая руда** | Низко (глубина > 20) | Высоко | Средко (арматура) | Низко | Средко |
| **Резонит** | Низко | Средко (глубинные жилы) | Низко | Высоко | Очень высоко |
| **Биоволокно** | Средко (растительные зоны) | Средко (пещерный мох) | Низко | Средко (островная флора) | Низко |
| **Биогель** | Низко | Средко (пещерные грибы) | Низко | Низко | Высоко (аномальная флора) |
| **Древние фрагменты** | Очень низко | Низко | Очень высоко | Средко (руины на островах) | Высоко |

### 3.1 Правила генерации

- **Жилы (veins):** ресурсы не рассыпаны по единичным тайлам, а образуют жилы — кластеры связанных тайлов одного типа. Размер жилы зависит от ресурса и биома.
- **Глубина:** ферритовая руда и резонит чаще на большей глубине (подземные пещеры).
- **Аномалии:** в аномальных зонах гравитация влияет на распределение — резонит плавает в зонах нулевой гравитации, биогель Konzentriertся вокруг гравитационных воронок.
- **Парящие острова:** ресурсы доступны только с привязкой к опорным колоннам или с использованием летучих аппаратов (для дронов).

## 4. Механика добычи (Mining)

### 4.1 Инструменты добычи

| Инструмент | Урон по тайлу | Скорость работы | Стамина/сек | Энергия/сек | Эффективность по материалам |
|------------|---------------|-----------------|-------------|-------------|----------------------------|
| Кирка камня | 5 | Нормальная | 3 | 0 | Камень, земля, руда |
| Кирка железа | 12 | Быстрая | 5 | 0 | Камень, земля, все руды |
| Лазерный резчик | 8 | Очень быстрая | 2 | 8 | Резонит, металл, постройки |
| Бур (ручной) | 3 | Медленная | 4 | 2 | Земля, камень, мягкие породы |
| Автоматический бур | 25 | Постоянная | 0 | 15 | Все породы (топливо/энергия) |
| Дрон-добытчик | 15 | Быстрая | 0 | 10 | Все ресурсы (дистанционно) |

### 4.2 Формула урона по тайлу

```
effectiveDamage = toolDamage × materialEffectiveness(tool, tileType) × staminaBonus

tileHealth -= effectiveDamage × dt
```

| Параметр | Описание |
|----------|----------|
| `toolDamage` | Базовый урон инструмента за удар |
| `materialEffectiveness` | Множитель 0.2 … 2.0 в зависимости от сочетания инструмент → материал (например, лазер по резониту = 2.0, кирка по резониту = 0.5) |
| `staminaBonus` | 1.0 … 1.5 в зависимости от текущей выносливости персонажа |
| `dt` | Шаг физики (1/60 сек) |

### 4.3 Разрушение тайла и спавн ресурса

Когда `tileHealth <= 0`:
1. Тилл в чанке помечается как `air` (удаляется из сетки).
2. Спавнится предмет-ресурс в мире (ES-сущность с `PhysicsBody`, `Renderable`, `ItemStack`):
   - `itemId` = `tile.resourceDrop`
   - `amount` = `tile.dropAmount × fortune(tool)` (фортуна инструмента 1.0 … 1.5)
   - Позиция = центр разрушенного тайла + небольшой разброс
3. Запускается проверка опоры соседних тайлов (физика осыпания, см. раздел 2.3).
4. Эмитит событие `tile:destroyed` в `EventBus` (для звука, частиц, сохранения карты).

### 4.4 Автоматические буры и дроны

- **Автоматический бур:** устанавливается как постройка (`construction` тайл), continuously наносит урон по тайлу под собой с интервалом, требует топлива/энергии.
- **Дрон-добытчик:** отдельная ECS-сущность с `AIController`, перемещается к целевому руднику, добывает ресурсы, возвращается на базу. Интегрируется с существующей `AISystem` и `InventorySystem`.

## 5. Интеграция с существующими системами

| Система | Интеграция |
|---------|------------|
| `GravitySystem` | Обломки destroyed тайлов получают индивидуальную гравитацию или попадают в зоны невесомости |
| `PhysicsSystem` | Обломки — физические тела Matter.js, 충돌ят с игроком и постройками |
| `InventorySystem` | Добытые ресурсы добавляются в инвентарь персонажа (stек, вес) |
| `StaminaEnergySystem` | Ручная добыча тратит выносливость и/или энергию |
| `EventSystem` | Гравитационные катастрофы могут destruir несколько тайлов одновременно (обрушения) |
| `SaveSystem` | Состояние чанков (разрушенные тайлы, поставленные постройки) сохраняется в IndexedDB |

## 7. Примеры

**Разрушение земляного тайла киркой камня:**
```
toolDamage = 5
materialEffectiveness(кирка, dirt) = 1.2
staminaBonus = 1.1 (выносливость 80%)
effectiveDamage = 5 × 1.2 × 1.1 = 6.6 за удар
tileHealth (dirt) = 20
Нужно 4 удара (20 / 6.6 ≈ 3.03)
При разрушении: спавн 1× "dirt" ресурса, проверка осыпания соседей
```

**Добыча резонита лазером в аномальной зоне:**
```
toolDamage = 8
materialEffectiveness(лазер, resonit_ore) = 2.0
tileHealth (resonit) = 40
effectiveDamage = 8 × 2.0 × 1.0 = 16 за удар
Нужно 3 удара (40 / 16 = 2.5)
При разрушении: спавн 2× "resonit" (fortune лазера 1.2)
```
