# GRAVITY: VOID — глобальное событие «Гравитационный прилив» и мутация мира

## 1. Обзор

**Гравитационный прилив (Gravity Tide)** — циклическое глобальное событие, которое периодически меняет правила мира: гравитация, ландшафт, распределение ресурсов и поведение существ. Прилив происходит независимо от действий игрока, но игрок может подготовиться к нему и защитить свою базу.

Цикл состоит из **4 фаз**:
1. **Стабильность** — обычный геймплей, накопление таймера до следующего прилива.
2. **Предупреждение** — визуальные и звуковые признаки approaching кризиса (цвет неба, левитация камней, гул, сканерный сигнал).
3. **Катастрофа** — смена вектора глобальной гравитации, разрушение незакреплённых построек, спавн опасных существ, деформация ландшафта.
4. **Последствия** — спавн новых руд, открытие заваленных пещер, сдвиг парящих островов, обнажение древних комплексов, новые аномальные зоны.

## 2. Стейт-машина события (Event State Machine)

```
[Stability] -- таймер истек --> [Warning] -- таймер истек --> [Catastrophe] -- таймер истек --> [Aftermath] -- таймер истек --> [Stability]
```

| Фаза | Длительность | Описание | Ключевые механики |
|------|-------------|----------|-------------------|
| **1. Стабильность** | 5–15 мин (настраивается) | Обычный геймплей. Таймер до предупреждения отображается в UI. | Нет специальных эффектов. |
| **2. Предупреждение** | 60–90 сек | Небо меняет цвет, мелкие камни левитируют, гул усиливается, сканер пищит. | Игрок получает сигнал准овиться. Сохранение доступно. |
| **3. Катастрофа** | 120–180 sec | Глобальная гравитация меняет вектор. Постройки без якоря разрушаются. Спаwn опасных существ. Жидкости текут по новому вектору. | Сохранение заблокировано. |
| **4. Последствия** | 60–120 сек | Новые руды, открытые пещеры, сдвинутые острова, обнажённые комплексы, новые аномалии. | Мир мутирует. Игрок может исследовать изменения. |

### 2.1 Переходы между фазами

```
TideManager.update(dt):
    phaseTimer += dt
    if phaseTimer >= phaseDuration:
        advanceToNextPhase()
        phaseTimer = 0
```

Каждая фаза имеет случайное отклонение длительности (±15%) для不可predictability.

### 2.2 Глобальное состояние прилива

Компонент `TideState` хранится на одной служебной сущности «мировой конфиг»:

```
TideState = {
  phase: 'stability' | 'warning' | 'catastrophe' | 'aftermath'
  phaseTimer: number          // секунд в текущей фазе
  phaseDuration: number       // запланированная длительность фазы
  cycleCount: number          // сколько приливов уже произошло
  globalGravityVector: Vec2   // текущий вектор глобальной гравитации
  nextGravityVector: Vec2     // вектор, который установится в фазе 3
  isSaveLocked: boolean       // сохранение заблокировано (фаза 3)
  warningSignal: boolean      // сигнал сканера активен (фаза 2)
}
```

## 3. Фаза 3: Катастрофа — воздействие на мир

### 3.1 Смена вектора глобальной гравитации

В начале фазы 3 `GravityTideSystem` меняет `TideState.globalGravityVector` на `nextGravityVector` (например, с `{0, 9.81}` на `{0, -9.81}` или `{9.81, 0}`). Вектор применяется ко всем физическим телам через `GravitySystem` и `PhysicsSystem`.

```
Гравитация меняется мгновенно, но тела инерционны — объекты продолжают движение по старой траектории некоторое время.
```

### 3.2 Защита построек: Гравитационные якоря и Энергетические купола

Постройки проверяются на защиту при смене гравитации:

| Защита | Эффект |
|--------|--------|
| **Гравитационный якорь** (`GravityAnchor`) | Постройки в радиусе якоря сохраняют позицию и ориентацию. Якорь потребляет энергию в секунду. |
| **Энергетический купол** (`EnergyDome` / щит) | Купол поглощает удар смены гравитации внутри своего радиуса. Постройки под куполом не разрушаются. Купол тратит энергию пропорционально количеству Protected построек. |

**Алгоритм проверки целостности в фазе 3:**

```
for each Structure:
    if structure.integrity <= 0: continue
    
    protected = false
    
    // Проверка Гравитационного Якоря
    for each GravityAnchor:
        if distance(structure, anchor) <= anchor.radius and anchor.active:
            protected = true
            break
    
    // Проверка Энергетического Купола
    if not protected:
        for each EnergyDome:
            if distance(structure, dome) <= dome.radius and dome.active and dome.energy > 0:
                protected = true
                dome.energy -= drainPerStructure * dt
                break
    
    if not protected:
        // Постройка теряет целостность при смене гравитации
        structure.integrity -= gravityChangeDamage * dt
        if structure.integrity <= 0:
            collapseStructure(structure)  // становится debris с физикой
```

### 3.3 Разрушение и перемещение предметов

- Предметы на земле (Item-сущности с `PhysicsBody`) получают импульс в новом векторе гравитации.
- Легкие объекты (масса < 5 кг) могут подняться в воздух при антигравитации.
- Жидкости (`Material.state === 'liquid'`) перетекают по новому вектору (через `FluidSystem` или упрощённую логику в `GravityTideSystem`).

### 3.4 Спавн опасных существ

В фазе 3 спавнится «приливная фауна» — существа, адаптированные к аномальной гравитации:
- Гравит-крокодилы (перемещаются по стенам/потолку)
- Аномальные поглотители (питаются энергией устройств)
- Приливные 방해тели (выбивают игрока из равновесия)

Спавн происходит в аномальных зонах и рядом с игроком.

## 4. Фаза 4: Последствия — мутация карты

### 4.1 Что меняется

| Изменение | Описание | Техническая реализация |
|-----------|----------|------------------------|
| **Новые руды** | Резонит, ферритовая руда и древние фрагменты появляются в новых жилах | `WorldMutation` спавнит `Mineable` тайлы в чанках |
| **Открытие пещер** | Заваленные туннели очищаются, открываются новые проходы | Удаление `stone`/`dirt` тайлов → `air` |
| **Сдвиг парящих островов** | Острова перемещаются на новые координаты | Пересоздание чанков островов в других местах |
| **Обнажение комплексов** | Заброшенные комплексы вскрываются после обвала грунта | Замена `dirt` → `construction` в зонах комплексов |
| **Новые аномалии** | Точки нулевой или инвертированной гравитации | Создание `GravityZone` сущностей |

### 4.2 Сохранение целостности игрока

Мутация карты **не ломает сохранения** игрока по следующим правилам:

1. **Постройки игрока не трогаются:** мутация применяется только к естественным тайлам (`dirt`, `stone`, `air`), never к `construction`.
2. **Инвентарь и экипировка нетронуты:** мутация карты не влияет на инвентарь.
3. **Позиция игрока сохраняется:** если игрок находится в зоне мутации, он перемещается в ближайшее безопасное место (не в стену).
4. **Сохранение чанков:** мутированные чанки помечаются как `dirty` и пересохраняются в `SaveSystem` с новой версией схемы.

### 4.3 Алгоритм применения мутации

```
WorldMutationSystem.applyMutations(world, mutations):
    for each mutation in mutations:
        switch mutation.type:
            case 'spawn_ore_vein':
                spawnOreVein(mutation.chunk, mutation.resourceType, mutation.position, mutation.size)
            case 'open_cave_passage':
                clearTiles(mutation.chunk, mutation.tiles, 'air')
            case 'shift_floating_island':
                moveChunkToNewLocation(mutation.chunkEntity, mutation.newChunkX, mutation.newChunkY)
            case 'expose_complex':
                replaceTiles(mutation.chunk, 'dirt'/'stone' → 'construction', mutation.area)
            case 'spawn_anomaly_zone':
                createGravityZone(mutation.position, mutation.vector, mutation.radius)
    
    // Помечаем изменённые чанки для сохранения
    for each chunk in mutatedChunks:
        chunk.lastModified = Date.now()
        eventBus.emit('chunk:dirty', { chunkEntity: chunk.entity })
    
    // Проверяем позицию игрока после мутации
    ensurePlayerNotInWall(playerEntity)
```

## 5. События системы прилива

| Событие | Данные | Когда |
|---------|--------|-------|
| `tide:phase-changed` | `{ from, to, cycleCount, phaseDuration }` | При смене фазы |
| `tide:gravity-changed` | `{ oldVector, newVector }` | При смене вектора гравитации (фаза 3) |
| `tide:warning-start` | `{ timeRemaining }` | Начало фазы 2 |
| `tide:catastrophe-start` | `{ gravityVector }` | Начало фазы 3 |
| `tide:catastrophe-end` | `{ cycleCount }` | Конец фазы 3 |
| `tide:aftermath-start` | `{ mutations: [...] }` | Начало фазы 4, список мутаций |
| `structure:at-risk` | `{ entity, anchor, dome }` | Постройка без защиты в фазе 3 |
| `world:mutated` | `{ mutations: [...] }` | После применения мутаций фазы 4 |

## 6. Интеграция с существующими системами

| Система | Интеграция |
|---------|------------|
| `GravitySystem` | Меняет глобальный вектор гравитации в фазе 3 |
| `PhysicsSystem` | Применяет импульсы к телам при смене гравитации |
| `ConstructionSystem` | Проверяет якоря и купола, разрушает незащищённые постройки |
| `DeviceSystem` | Энергетические купола потребляют энергию во время прилива |
| `SaveSystem` | Блокирует сохранение в фазе 3, сохраняет мутированные чанки в фазе 4 |
| `AISystem` | Спавнит опасных существ в фазе 3 |
| `MiningSystem` / `ChunkSystem` | Применяет мутации карты в фазе 4 |
| `DeathSystem` | Сохранение заблокировано в фазе 3 (см. Hardcore) |
