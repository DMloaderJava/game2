# GRAVITY: VOID — план реализации MVP (вертикальный срез)

## Цель прототипа
Замкнутый игровой цикл: **Исследование → Добыча → Развитие → Подготовка → Катастрофа → Последствия**.

## Ограничение объёма (СКОУП MVP)
| Компонент | Что в MVP | Что НЕ в MVP |
|-----------|-----------|--------------|
| Локация | Поверхность + небольшая пещера (закрыта до катастрофы) | Все 5 биомов, парящие острова |
| Персонаж | Движение, прыжок, здоровье, энергия, выносливость, grab/throw | Карабканье по стенам, сканирование |
| Физика | Гравитация на игрока, лут, постройки | Жидкости, ветер, сложные материалы |
| Ресурсы (6) | Каменные плиты, феррит, резонит, биоволокно, биогель, древние фрагменты | — |
| Добыча | Кирка, разрушение тайлов, инвентарь, простой UI крафта | Автоматические буры, дроны |
| Строительство | Фундамент, стена, потолок, дверь, хранилище | Лестницы, платформы, защита |
| Устройства (1) | Гравитационный якорь | Генератор, конвейер, турель, сканер |
| Способности (2) | Притяжение, Отталкивание | Остальные способности веток |
| Существа (2) | Мирный сборщик, хищник (реакция на гравитацию) | Все остальные мобы, боссы |
| Событие (1) | Один полный цикл Гравитационного прилива | Повторяющиеся циклы, случайные аномалии |
| Системы | Смерть/возрождение (потеря части лута), сохранение в IndexedDB | Экспорт/импорт сейвов, миграции |

## Этап 1: Ядро и рендеринг (Дни 1–2)
1. Установить `pixijs` и `matter-js`
2. Создать `src/core/engine.ts` — точка входа, инициализация PixiJS Application + Matter.js Engine
3. Создать `src/core/renderer.ts` — обёртка PixiJS (слои, камера, спрайты сущностей)
4. Создать `src/core/physics-world.ts` — обёртка Matter.js Engine/World
5. Обновить `src/main.ts` — запуск движка, создание мира ECS, первый кадр
6. Заменить `index.html` — контейнер для игры, HUD-заглушки

## Этап 2: Игровой цикл и ECS (Дни 2–3)
1. Интегрировать существующий ECS (`src/ecs/*`) с PixiJS + Matter.js
2. `GameLoop` — фиксированный шаг 60 FPS + интерполированный рендер
3. Система рендеринга: создание/удаление спрайтов PixiJS по компонентам `Transform + Renderable`
4. Система физики: Matter.js шаг, синхронизация тел → `Transform`
5. Спавн игрока (сущность с `Transform`, `PhysicsBody`, `CharacterController`, `CharacterStats`)
6. Базовая геометрия уровня: земля, několik блоков камня, вход в пещеру (закрыт камнем)

## Этап 3: Персонаж и управление (Дни 4–5)
1. `CharacterSystem` — состояния Grounded/Airborne, движение, прыжок (против вектора гравитации)
2. `StaminaEnergySystem` — расход/восстановление выносливости и энергии
3. Ввод: WASD/стрелки + пробел, мышь для ориентации
4. Камера: follow за игроком с плавной интерполяцией
5. UI: полоски здоровья/энергии/выносливости, таймер прилива

## Этап 4: Добыча и инвентарь (Дни 6–7)
1. `MiningSystem` — клик мышкой, урон киркой по тайлу, разрушение, спавн предмета-ресурса
2. `InventorySystem` — слоты, стак, подбор предмета ( proximity + E )
3. UI инвентаря: сетка слотов, перетаскивание, отображение веса
4. `CraftingSystem` — 2–3 простых рецепта (каменная плита из камня, фундамент из плит)

## Этап 5: Строительство и якорь (Дни 8–9)
1. `ConstructionSystem` — размещение блоков (фундамент, стена, потолок, дверь, хранилище) по сетке
2. Призрачное превью, проверка опоры, потрата ресурсов из инвентаря
3. `GravityAnchor` — устройство, удерживает постройки в радиусе при смене гравитации
4. Крафт якоря через рецепт

## Этап 6: Способности (2 шт.) (День 10)
1. `AbilitySystem` — слоты способностей, коундауны, энергия
2. `gravity_pull` — притягивает ближайшие физические тела к игроку
3. `gravity_push` — отталкивает тела в радиусе от игрока
4. Клавиши Q/E для активации, визуальный эффект (круг вокруг игрока)

## Этап 7: Существа (2 вида) (День 11)
1. `AISystem` — базовое поведение
2. Мирный сборщик: ходит, добывает камень, убегает от игрока
3. Хищник: преследует игрока, реагирует на изменение гравитации, может быть отвлечён броском предмета
4. Физические тела для существ, урон при столкновении

## Этап 8: Гравитационный прилив (один цикл) (Дни 12–13)
1. `GravityTideSystem` — стейт-машина 4 фаз (Стабильность → Предупреждение → Катастрофа → Последствия)
2. Фаза 2: смена цвета неба, частицы левитирующих камней, звук тревоги, сигнал сканера
3. Фаза 3: инверсия гравитации, разрушение построек без якоря, спавн хищника
4. Фаза 4: открытие прохода в пещеру (удаление камня), спавн жил резонита, сброс гравитации

## Этап 9: Смерть, возрождение, сохранение (День 14)
1. `DeathSystem` — здоровье 0 → состояние Dead, дроп части инвентаря, возрождение на спавне через 3 сек
2. `SaveSystem` — IndexedDB: сохранение чанков, инвентаря, прогрессии, позиций построек
3. Загрузка при запуске, автосейв каждые 30 сек

## Этап 10: Полировка и сборка (День 15)
1. Звуковые эффекты (Howler.js заглушки), partículas
2. UI: главное меню, экран смерти, экран прилива
3. Сборка `npm run build`, проверка на превью
4. Коммит MVP-версии
