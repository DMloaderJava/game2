# GRAVITY: VOID — система способностей и прогрессии персонажа

## 1. Обзор

Развитие персонажа открывает **новые механики**, а не просто бустит статы. Есть 5 веток прокачки, каждая со своим стилем игры:

| Ветка | Стиль | Ключевые механики |
|-------|-------|-------------------|
| **Гравитация** | Контроль поля | Притяжение, отталкивание, смена веса, невесомость, локальные поля |
| **Передвижение** | Мобильность | Прыжки, грави-рывок, бег по стенам, ускорение, контроль в воздухе |
| **Энергия** | Боевой интеллект | Импульсы, щиты, поглощение урона, взлом механизмов |
| **Биология** | Адаптация | Изучение фауны, био-улучшения, свойства существ |
| **Технологии** | Автоматизация | Сложный крафт, апгрейды устройств, древние технологии |

Важна **синергия**: комбинации способностей дают эффекты, недоступные по отдельности.

## 2. Архитектура Ability System (модульная)

### 2.1 Принцип

Способность — это независимый модуль с чётким интерфейсом. Ядро не знает о конкретных способностях; оно только выполняет эффекты и обнаруживает комбинации. Новые способности добавляются плагинами (ветками прокачки) без изменения ядра.

### 2.2 Компоненты

```
AbilityDefinition          — шаблон способности (регистрируется плагином)
AbilitySlot               — ячейка способности у персонажа (активирована/коундаун)
ActiveEffect              — экземпляр действия способности в реальном времени
AbilityCombo              — обнаруженная синергия двух+ активных эффектов
SkillTreeNode             — узел дерева навыков (разблокировка способности)
ProgressionData           — уровень веток, очки навыка, опыт персонажа
ScanKnowledge             — полученное при сканировании знание об объектах
```

### 2.3 Жизненный цикл способности

1. **Открытие:** сканирование мира → получение образцов/фрагментов → разблокировка узла в дереве навыков
2. **Оборудование:** способность попадает в пустой слот `AbilitySlot`
3. **Активация:** игрок нажимает клавишу → создаётся `ActiveEffect` с длительностью/коундауном
4. **Синергия:** если одновременно активны совместимые эффекты — создаётся `AbilityCombo` с усилённым результатом
5. **Завершение:** эффект истекает, слот уходит в коундаун

## 4. Система комбинаций (Синергия)

Синергия срабатывает, когда два или более активных эффекта совместимы и воздействуют на одну цель или область.

### 4.1 Поддерживаемые связки

| Связка | Способности | Результат |
|--------|------------|-----------|
| **Притяжение + Грави-рывок** | Притяжение + Грави-рывок | Персонаж притягивает объект, затем瞬间 перемещается к нему (быстрое перемещение к цели) |
| **Невесомость + Отталкивание** | Невесомость + Отталкивание | Объекты в зоне невесомости разбрасываются во все directions с удвоенной силой (гравитационная волна) |
| **Притяжение + Отталкивание** | Притяжение + Отталкивание | Сжатие объекта в точку (иMPLOSION), урон по области |
| **Энергетический импульс + Щит** | Импульс + Щит | Щит взрывается, нанося урон вокруг и отбрасывая врагов |
| **Бег по стенам + Грави-рывок** | Бег по стенам + Рывок | Рывок вдоль поверхности стены/потолка без потери импульса |

### 4.2 Примеры расчёта синергии

**Притяжение + Грави-рывок:**
```
1. Активировать Притяжение к объекту X — объект летит к игроку
2. В течение 1.5 сек активировать Грави-рывок
3. Синергия: игрок телепортируется к объекту X, сохраняя импульс рывка
4. Энергия: стоимость обеих способностей − 20% скидка за синергию
```

**Невесомость + Отталкивание:**
```
1. Активировать Невесомость в зоне радиуса 5 м
2. Активировать Отталкивание
3. Синергия: все объекты в зоне получают импульс от центра в случайном направлении с коэффициентом 2.0
4. Эффект: «гравитационная бомба» — разбрасывает группу объектов и сущностей
```

### 4.3 Обнаружение комбинаций

```
AbilitySystem.detectCombos(activeEffects):
    for each pair (effectA, effectB) in activeEffects:
        if comboRegistry.has(effectA.id, effectB.id):
            combo = comboRegistry.get(effectA.id, effectB.id)
            if targets overlap or same caster:
                create AbilityCombo(combo.type, combo.multiplier, involvedEffects)
```

## 5. Механика получения способностей

### 5.1 Поток прогрессии

```
Сканирование мира → Образцы (био/древние/ресурсы) → Очки навыка → Дерево навыков → Способности
```

### 5.2 Сканирование

- **Сканер** (устройство из ветки Технологий или стартовое оборудование)
- Активное сканирование области выделяет объекты: существа, руины, аномалии, ресурсы
- Результат: `ScanKnowledge` — запись о сканированном объекте с типом и свойствами
- Сканирование тратит Энергию (см. `StaminaEnergySystem`)

### 5.3 Источники очков навыка

| Источник | Что даёт | Использование |
|----------|----------|---------------|
| Сканирование нового существа | Био-образец | Ветка Биология |
| Сканирование руин/артефакта | Древний фрагмент | Ветка Технологии |
| Добыча резонита | Ресурс грави-технологий | Ветка Гравитация |
| Исследование сложных постероек | Очки инженерии | Ветка Технологии |
| Исследование бега по стенам / прыжков | Очки мобильности | Ветка Передвижение |
| Поглощение энергетических аномалий | Очки энергии | Ветка Энергия |

### 5.4 Разблокировка способности

```
unlockAbility(abilityId):
    1. Проверить предварительные условия (родительские узлы в дереве)
    2. Проверить наличие необходимых ресурсов (фрагменты, образцы, очки)
    3. Списать ресурсы
    4. Пометить способность как разблокированную (ProgressionData)
    5. Добавить в пустой AbilitySlot игрока (если есть место)
    6. Эмитит событие ability:unlocked
```

### 5.5 Дерево навыков (структура)

```
Каждая ветка — линейное дерево с ветвлениями на высоких уровнях:

Уровень 1: Базовая способность (доступна после первого сканирования соответствующего типа)
    ↓
Уровень 2: Улучшенная версия (требует 1 очко ветки + 1 ресурс)
    ↓
Уровень 3: Сильная способность (требует 2 очка + 2 ресурса + сканирование 3 объектов типа)
    ↓
Уровень 4: Мастерская (требует 3 очка + уникальный ресурс)
    ↓
Уровень 5: Финальная (требует 4 очка + древний артефакт)
```

## 6. Интеграция с существующими системами

| Система | Интеграция |
|---------|------------|
| `GravitySystem` | Способности гравитации меняют `IndividualGravity` и создают `GravityZone` |
| `PhysicsSystem` | Импульсы способностей применяются как силы к телам Matter.js |
| `StaminaEnergySystem` | Активация способностей тратит Энергию; коундауны зависят от восстановления |
| `CharacterSystem` | Способности передвижения меняют состояние стейт-машины (ZeroG, Climbing и т.д.) |
| `InventorySystem` | Ресурсы для разблокировки хранятся в инвентаре |
| `MiningSystem` / `ChunkSystem` | Способности могут разрушать или создавать тайлы (например, грави-ловушка) |
| `DeviceSystem` | Взлом механизмов временно подчиняет устройства игроку |
| `DeathSystem` | При смерти Softcore способности сохраняются (разблокировка перманентна) |

## 7. События Ability System

| Событие | Данные | Когда |
|---------|--------|-------|
| `ability:unlocked` | `{ abilityId, branch, level }` | Способность разблокирована |
| `ability:activated` | `{ abilityId, slot, entity }` | Способность активирована |
| `ability:deactivated` | `{ abilityId, slot, entity }` | Способность деактивирована (конец длительности) |
| `ability:combo` | `{ comboType, abilities[], multiplier, target }` | Обнаружена синергия |
| `scan:completed` | `{ entity, knowledge, bioSample, fragment }` | Сканирование закончено |
| `progression:level-up` | `{ branch, newLevel }` | Уровень ветки повышен |
