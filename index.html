GRAVITY: VOID

2D Side-scroller · Survival / Sandbox / RPG / Physics · Веб-браузер

Статус проекта

Репозиторий содержит архитектурную документацию и эталонную реализацию ядра ECS на TypeScript. Это файл 설계 — игра ещё не собрана.

Ветка: arena/250eb9d3-game2 Ядро: ECS (Entity-Component-System) Рендер: PixiJS v8 (WebGL) Физика: Matter.js Звук: Howler.js Хранение: IndexedDB Сборка: Vite + TypeScript

Документация

  • 01-tech-stack.md — выбор технологий
  • 02-architecture.md — ECS-архитектура, модульность, плагины
  • 03-systems.md — 8 базовых систем (физика, рендер, ввод, инвентарь, строительство, ИИ, события, сохранения)
  • 04-interaction.md — схема взаимодействия модулей (Mermaid)
  • 05-folder-structure.md — структура папок проекта

Исходный код (ядро ECS)

src/ecs/world.ts — World (сущности, компоненты, системы, query)
src/ecs/system.ts — базовый класс System
src/ecs/component.ts, entity.ts, query.ts — примитивы ECS
src/core/event-bus.ts — шина событий pub/sub
src/core/game-loop.ts — фиксированный шаг 60 FPS + интерполированный рендер
src/core/types.ts — типы GameConfig, Plugin, ServiceLocator
src/components/ — чистые данные (Transform, PhysicsBody, Renderable, Player, GravityZone, Intent*)
src/systems/ — InputSystem, AISystem, PhysicsSystem, ConstructionSystem, InventorySystem, EventSystem, RenderSystem, SaveSystem
src/services/ — обёртки над PixiJS, Matter.js, Howler.js, IndexedDB, ввод
src/modules/biomes/void-biome.ts — пример плагина биома (не меняет ядро)
src/main.ts — точка входа, сборка мира и запуск GameLoop

Команды разработки

npm run typecheck # проверка типов TypeScript
npm run dev # запуск dev-сервера (текущий превью)
npm run build # сборка в dist/

Архитектура позволяет добавлять биомы, способности, предметы и типы ИИ через плагины, не переписывая ядро ECS. Высокая производительность обеспечивается спрайт-батчингом PixiJS, sleeping-телами и эффективным broadphase Matter.js.
